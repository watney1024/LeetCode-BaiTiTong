### 第 4 次学习 · 2026-10-06

**内容：** Day 1 二刷收口——哈希 + 双指针 7 题重做完毕。**49 字母异位词分组 / 128 最长连续序列 / 15 三数之和 标记待三刷**，其余 4 题勾 ✅。Day01 笔记已回填（思路 / 代码引用 / 复杂度 / 三态 + 各疑问解答），128 代码修正 TLE（外层改遍历 `mp` 键，根因是重复链起点重走链，非哈希碰撞）。

**代码走查发现（cpp 工程）：**
- 49：`for (auto c : strs)` / `for (auto c : mp)` 逐元素拷贝，应 `const auto&`；`count`+`[]` 双查找可用 `push_back` 一句替代；`encoding` 参数应 `const string&`。
- 1：`count` + `operator[]` 双查找 → `find` 一次。
- 42：`sz==0` 时 `right[sz-1]` 越界（线上约束 n≥1 不炸，本地测空会），建议开头加空判。
- 15 / 128：无正确性问题；128 已自修。

**知识增量（对照 49 参考题解 + 追问）：**
- **49 编码 key 两种方案**：labuladong 版把 26 字母频次直接 `++` 进一个 26 字节 string 当 key——短、哈希快，但频次超 127 形式上是 signed char 溢出 UB（靠串长 ≤100 侥幸安全）；我的 `#`+`to_string` 计数编码更稳。**结论：保留自己的编码，记住 trick 存在。**
- **`list<string>` 在 49 里是多余的**：每题只整体收集一次，`vector` 更好（`list` 每节点单独堆分配）。
- **收集结果用 `std::move`**：`for (auto& [k, v] : mp) res.push_back(std::move(v));` 零拷贝搬走 map 的 value——上一版双方都在拷全部字符串。
- **拷贝问题三解法口诀**：引用（避免拷贝）、move（转移拷贝）、改数据结构（避免存在）。
- **前缀 `++` 习惯**：类类型迭代器的 `it++` 必须构造旧值副本（`operator++(int)`），`++it` 返回引用零开销 → 默认写前缀；真需要"先用后加"就拆两行写。

**遗留问题：**
- 三刷队列：49（编码 key + 引用习惯）、128（起点法遍历域）、15（NSum 生成时去重）；顺带 42 三刷时补 O(1) 空间对撞版。

**代码走查发现（cpp 工程）：**

- 48：翻转段上界 `j <= n/2` → 改 `j < n/2`；n=1..5 全部与期望一致（改前 n=2、n=4 错）。
- 54：无正确性问题，两个判空位置正确；同样有「取 `matrix[0]` 早于空判」的毛病。
